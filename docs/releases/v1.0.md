대화창 줄 넘침과 결과·스코어·기록 화면의 그림 글씨를 고친 정식 버전입니다.

**원본 일본판에 적용하는 전체 패치입니다.** 이전 한글 패치 롬에 덧씌울 수 없습니다.

## 변경 사항

### 대사

- 통신·컷신 대화창의 줄 폭을 112px에서 108px로 줄여, 줄이 꽉 차면 마지막 글자가 창 테두리에 닿던 문제를 고쳤습니다.
- 줄 폭 변경에 맞춰 대사 14개를 원문 뜻을 살려 다듬었습니다(16, 68, 88, 109, 114, 120, 135, 141, 181, 193, 198, 202, 206, 212번).
- 울프 대사(181번)의 뜻이 뒤집혀 있던 오역을 "여기부턴 못 지나가게 해 주지!"로 고쳤습니다.

### 결과 보고 화면

- 상단의 작은 "랭크" 라벨이 거의 보이지 않던 문제를 원본처럼 둥근 초록 판 위 흰 글씨로 고쳤습니다.
- "코네리아 대미지 005 %" 옆과 "사용 안 함" 왼쪽의 잔여 픽셀을 지웠습니다.

### 스코어 화면

- 제목 "スコア トップ5"를 **스코어 베스트 5**로 한글화했습니다.
- 오른쪽 위 "토털" 글자 잘림을 고치고, 제목줄 라벨(사인·파일럿·토털 스코어·타임·랭크)을 판 가운데에 맞췄습니다.
- 재도전·타이틀 버튼에 다른 버튼의 글자 조각이 섞여 보이던 문제를 고치고, 원본처럼 굵은 글씨로 바꿨습니다.

### 기록 메뉴

- "기록보기" 버튼 글씨가 뭉개지고 원문 조각이 남던 문제를 고쳤습니다. 릴리즈 뒤에 패치 파일을 교체했으며, 아래 확인값은 교체한 파일 기준입니다.
