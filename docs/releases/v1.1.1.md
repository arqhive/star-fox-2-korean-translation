대사에서 같은 뜻의 단어가 섞여 쓰이던 것을 바로잡은 작은 수정판입니다. 그림 글씨·폰트·게임 코드는 v1.1과 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** 기존 v1.1 한글판을 쓰고 있다면 업그레이드 패치를 쓰면 됩니다.

## 변경 사항

- 003번 대사의 중복 표현을 고쳤습니다. "대형 항공모함과 **항모**에서 출격한"을 "대형 항공모함과 **거기서** 출격한"으로 바꿨습니다. 원문 「空母と 空母から」는 같은 단어를 두 번 쓴 것인데, 번역에서 다른 말로 옮겨 배가 두 척인 것처럼 읽혔습니다.
- 원문이 모두 空母이므로 나머지 대사의 "항모"도 **"항공모함"**으로 통일했습니다(120·134·160·161·162번).
- 줄 길이에 맞춰 120번은 "코네리아로 향하라"를 "코네리아로"로, 160번은 "안돌프의"를 "안돌프"로 줄였습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFox2_JP_Korean_v1.1.1.zip` | | 아래 패치 3종과 사용자 설명서, 라이선스. |
| `StarFox2_JP_Korean_v1.1.1.bps` | 원본 일본판 | 권장. |
| `StarFox2_JP_Korean_v1.1.1.ips` | 원본 일본판 | BPS를 쓸 수 없는 도구용. |
| `StarFox2_Korean_v1.1_to_v1.1.1.bps` | 기존 v1.1 한글판 | 업그레이드용. |

입력 롬에 맞는 패치 하나만 적용하세요. 어느 패치를 써도 결과는 같습니다.

2. 결과 롬의 확인값을 아래 표와 비교합니다.
