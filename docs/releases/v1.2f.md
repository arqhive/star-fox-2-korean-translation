**최종판입니다.** 번역과 그림 글씨 검수를 모두 마쳤습니다. 그림 글씨·폰트·게임 코드는 v1.1.2와 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** 기존 v1.1.2 한글판을 쓰고 있다면 업그레이드 패치를 쓰면 됩니다.

## 변경 사항

- 177번 울프 대사의 말투를 "장사 경쟁자는 이쯤에서 사라져 줘야겠군!!"에서 "사라져 줘야겠어!!"로 고쳤습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFox2_KO_v1.2f.zip` | | 아래 패치 3종과 사용자 설명서, 라이선스. |
| `StarFox2_KO_v1.2f.bps` | 원본 일본판 | 권장. |
| `StarFox2_KO_v1.2f.ips` | 원본 일본판 | BPS를 쓸 수 없는 도구용. |
| `StarFox2_KO_v1.1.2_to_v1.2f.bps` | 기존 v1.1.2 한글판 | 업그레이드용. |

입력 롬에 맞는 패치 하나만 적용하세요. 어느 패치를 써도 결과는 같습니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 입력 롬에 패치를 적용합니다.
2. 결과 롬의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
