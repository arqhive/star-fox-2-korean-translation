작은 그림 글씨의 획이 뭉치거나 외곽선이 잘리던 부분을 다듬은 업데이트입니다. 라벨 12개를 고쳤으며, 대사·폰트 데이터·게임 코드는 v1.0과 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** 기존 v1.0 한글판을 쓰고 있다면 업그레이드 패치를 쓰면 됩니다.

## 변경 사항

- 맵 HUD의 '코네리아 대미지'에 자동 축소 대신 전용 6픽셀 글리프를 써서 획 사이 간격을 살렸습니다.
- '셀렉트·컨트롤'과 '기록삭제·토털·점수·재도전·타이틀·기록보기'의 과도한 굵게 처리를 없애 글자 안쪽 공간과 획을 또렷하게 했습니다.
- 일시정지 메뉴 '배틀 계속·맵으로 복귀·카메라'의 그림자를 타일 안에 온전히 들어가게 바꿨습니다.
- 그래픽 빌드에 글자·그림자·외곽선 잘림 검사를 추가했습니다.
- 그래픽 스트림 4개와 체크섬 외의 데이터는 v1.0과 같습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `StarFox2_JP_Korean_v1.1.zip` | | 아래 패치 3종과 사용자 설명서, 라이선스. |
| `StarFox2_JP_Korean_v1.1.bps` | 원본 일본판 | 권장. |
| `StarFox2_JP_Korean_v1.1.ips` | 원본 일본판 | BPS를 쓸 수 없는 도구용. |
| `StarFox2_Korean_v1.0_to_v1.1.bps` | 기존 v1.0 한글판 | 업그레이드용. |

입력 롬에 맞는 패치 하나만 적용하세요. 어느 패치를 써도 결과는 같습니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 입력 롬에 패치를 적용합니다.
2. 결과 롬의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
