# 스타폭스 2 한글 패치 v1.1.1

대사에서 같은 뜻의 단어가 섞여 쓰이던 것을 바로잡은 작은 수정판입니다. 그림 글씨·폰트·게임 코드는 v1.1과 같습니다.

## v1.1 대비 변경 사항

- 003번 대사의 중복 표현 수정: "대형 항공모함과 **항모**에서 출격한" → "대형 항공모함과 **거기서** 출격한".
  원문 「アンドルフ軍の大型空母と 空母から出撃した 攻撃部隊が」는 같은 단어(空母)를 두 번 쓴 것인데, 번역에서 서로 다른 말로 옮겨 배가 두 척인 것처럼 읽혔습니다.
- 원문이 모두 空母이므로 나머지 대사의 "항모"도 **"항공모함"**으로 통일 (120·134·160·161·162번).
  줄 길이에 맞춰 120번은 "코네리아로 향하라"를 "코네리아로"로, 160번은 "안돌프의"를 "안돌프"로 줄였습니다.

## 다운로드 및 적용

- `StarFox2_JP_Korean_v1.1.1.zip`: 아래 패치 3종, 한국어 설명서, 라이선스 포함.
- `StarFox2_JP_Korean_v1.1.1.bps`: **원본 일본판**에 적용하는 BPS 패치 (권장).
- `StarFox2_JP_Korean_v1.1.1.ips`: 원본 일본판에 적용하는 IPS 패치.
- `StarFox2_Korean_v1.1_to_v1.1.1.bps`: **기존 v1.1 한글판**에 적용하는 업그레이드 패치.

입력 롬에 맞는 패치 하나만 적용하세요. 세 패치의 최종 결과는 같습니다.

| 구분 | CRC32 | SHA1 |
|---|---|---|
| 원본 일본판 (헤더 없음) | `3753682F` | `578df9cc661548f278faa1fb4b9b2e9701bde92e` |
| 기존 v1.1 한글판 | `F9F6E81E` | `a398c11656ee922b0f9664c15b2968a93904468d` |
| v1.1.1 적용 결과 | `CCF4A953` | `307dcb87a40d71ed34e4fa116a1f5b444fad74fb` |

세 롬 모두 1,048,576바이트입니다. 일본판은 Classic Mini·Switch Online 덤프를 기준으로 하며 북미·유럽판에는 적용되지 않습니다.

## 검증

- 수정한 6개 대사를 포함해 216개 전체의 자동 줄바꿈을 두 대화창 폭(108px·127px)에서 확인 — 모두 3줄 이내.
- 그림 글씨 8개 블록과 MISSION 패널의 압축 해제 결과가 v1.1과 완전히 동일함을 확인.
- BPS 2종과 IPS 1종을 각각 적용해 같은 롬이 나오는지 확인.

게임 롬은 포함하지 않습니다. 비공식 팬 번역이며 Nintendo와 관련이 없습니다.
