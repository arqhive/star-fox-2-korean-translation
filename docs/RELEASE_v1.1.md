# 스타폭스 2 한글 패치 v1.1

작은 그림 글씨의 획이 뭉치거나 외곽선이 잘리던 부분을 다듬었습니다. 총 12개 라벨을 개선했으며, 제작자 인게임 확인을 마쳤습니다.

## v1.0 대비 변경 사항

- 맵 HUD의 ‘코네리아 대미지’: 자동 축소 대신 전용 6픽셀 글리프를 사용해 획 사이 간격을 보존.
- ‘셀렉트·컨트롤’ 및 ‘기록삭제·토털·점수·재도전·타이틀·기록보기’: 과도한 굵게 처리를 제거해 글자 내부 공간과 획을 또렷하게 개선.
- 일시정지 메뉴 ‘배틀 계속·맵으로 복귀·카메라’: 타일 안에 온전히 들어가는 그림자로 변경.
- 그래픽 빌드 시 글자·그림자·외곽선의 잘림 검사 추가.

원본과 같은 1MB 크기이며, 그래픽 스트림 4개와 체크섬 외의 모든 데이터는 v1.0과 동일합니다. 대사·폰트 데이터·게임 코드는 변경하지 않았습니다.

## 다운로드 및 적용

- `StarFox2_JP_Korean_v1.1.zip`: 아래 패치 3종, 한국어 설명서, 라이선스 포함.
- `StarFox2_JP_Korean_v1.1.bps`: **원본 일본판**에 적용하는 BPS 패치 (권장).
- `StarFox2_JP_Korean_v1.1.ips`: 원본 일본판에 적용하는 IPS 패치.
- `StarFox2_Korean_v1.0_to_v1.1.bps`: **기존 v1.0 한글판**에 적용하는 업그레이드 패치.

입력 롬에 맞는 패치 하나만 적용하세요. 세 패치의 최종 결과는 같습니다.

| 구분 | CRC32 | SHA1 |
|---|---|---|
| 원본 일본판 (헤더 없음) | `3753682F` | `578df9cc661548f278faa1fb4b9b2e9701bde92e` |
| 기존 v1.0 한글판 | `EE7AB3D3` | `89f871e2e12d10a8460cc10996a4829296091dad` |
| v1.1 적용 결과 | `F9F6E81E` | `a398c11656ee922b0f9664c15b2968a93904468d` |

세 롬 모두 1,048,576바이트입니다. 일본판은 Classic Mini·Switch Online 덤프를 기준으로 하며 북미·유럽판에는 적용되지 않습니다.

## 검증 및 남은 제약

- 제작자 인게임 확인 완료.
- 수정한 4개 블록을 게임의 원래 압축 해제 루틴으로 복원하여 확인.
- 그래픽 밖 데이터 보존, 체크섬, BPS·IPS 재적용 결과 검증.
- 스코어 화면 ‘파일럿’의 약간 왼쪽 정렬은 공유 타일 제약으로 유지.
- 대화창 넘김 표시(▼) 겹침과 일부 작은 라벨의 촘촘한 배치는 기존과 동일.
- 실기·공식 에뮬레이터 지원 범위는 이번 확인으로 확대하지 않았습니다.

게임 롬은 포함하지 않습니다. 비공식 팬 번역이며 Nintendo와 관련이 없습니다.
