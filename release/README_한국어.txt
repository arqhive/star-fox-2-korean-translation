 스타폭스 2 (슈퍼 패미컴 일본판) 한글 패치 v1.0
 Star Fox 2 - Korean Patch
==============================================================

제작: arqhive
배포 파일: StarFox2_JP_Korean_v1.0.bps  (권장)
           StarFox2_JP_Korean_v1.0.ips  (BPS를 못 쓰는 도구용)


■ 소개
--------------------------------------------------------------
슈퍼 패미컴 "스타폭스 2" 일본판을 한국어로 즐길 수 있게 하는
비공식 팬 한글 패치입니다. 대사는 일본어판 원문을 기준으로 번역했습니다.

- 게임 내 대사 216개 전체 한글화
- 한글 폰트 추가 (Galmuri)
- 그림 글씨 한글화
  (맵 화면 HUD / 파일럿 선택 / 조작 설정 / 결과·기록 화면 /
   일시정지 메뉴 / MISSION 설명 패널 등)


■ 준비물
--------------------------------------------------------------
1) 본인이 직접 덤프한 일본판 원본 롬 (헤더 없는 .sfc)
   - 예: Star Fox 2 (Japan) (Classic Mini, Switch Online).sfc
   - 크기 : 1,048,576 바이트
   - CRC32: 3753682F
   - MD5  : e7de4068dd0577ec5567783739839a76
   - SHA1 : 578df9cc661548f278faa1fb4b9b2e9701bde92e

   ※ 북미·유럽판(영어판) 롬에는 적용되지 않습니다.
   ※ 512바이트 헤더가 붙은 롬(크기 1,049,088)은 헤더를 제거한 뒤 적용하세요.
   ※ 게임 롬 파일은 배포하지 않습니다. 반드시 본인이 소유한 게임에서 덤프하세요.

2) 패치 적용 도구 (둘 중 하나)
   - Rom Patcher JS (웹 브라우저): https://www.marcrobledo.com/RomPatcher.js/
   - Floating IPS (Windows)


■ 패치 적용 방법
--------------------------------------------------------------
[Rom Patcher JS]
 1. 사이트를 열고 "ROM file"에 원본 롬을 선택
 2. "Patch file"에 StarFox2_JP_Korean_v1.0.bps 선택
 3. "Apply patch" → 한글판 롬 저장

[Floating IPS]
 1. "Apply Patch" → StarFox2_JP_Korean_v1.0.bps 선택
 2. 원본 롬 선택 → 저장할 파일 이름 입력

BPS 패치는 원본 해시를 자동으로 검사하므로, 원본이 다르면 적용이 거부됩니다.
IPS 패치는 검사하지 않으니 적용 후 아래 해시로 확인하세요.

 적용 결과 (한글판)
   - 크기 : 1,048,576 바이트 (원본과 같은 크기)
   - CRC32: EE7AB3D3
   - SHA1 : 89f871e2e12d10a8460cc10996a4829296091dad


■ 실행 환경
--------------------------------------------------------------
- 확인: Mesen 2 (PC 에뮬레이터), 스테이지 플레이 → 결과 보고·스코어·기록 화면까지
- 권장: Mesen, bsnes/higan, Snes9x 등 슈퍼FX를 지원하는 PC 에뮬레이터
- 미확인: SNES Classic Mini / Nintendo Switch Online / FXPak Pro
  (원본과 같은 1MB 구조라 동작할 것으로 예상하지만 확인하지 못했습니다)
- 불가: SNES 에버드라이브 (슈퍼FX 미지원, 원본도 실행되지 않음)


■ 알려진 문제
--------------------------------------------------------------
- 맵 화면 대화창에서 줄이 꽉 찬 경우 넘김 표시(▼)가 마지막 글자와 조금 겹칠 수 있습니다.
- 작은 라벨은 공간이 좁아 글자가 촘촘합니다.
- 스코어 화면의 "파일럿" 라벨은 판 가운데보다 약간 왼쪽에 있습니다.
- EXPERT 레벨 안내 등 일부 그림 글씨는 확인하지 못했습니다.
